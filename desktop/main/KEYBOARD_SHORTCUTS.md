# Care Connect Hearing — Keyboard Shortcuts

## General Navigation

| Shortcut | Action |
|----------|--------|
| Tab | Move to next interactive element |
| Shift + Tab | Move to previous interactive element |
| Enter | Activate selected element |
| Esc | Close dialog / Cancel action |
| F1 | Open Help |

## File Operations

| Shortcut | Action |
|----------|--------|
| Ctrl + N | New Message |
| Ctrl + S | Save / Send Message |
| Ctrl + Q | Quit Application |

## Editing

| Shortcut | Action |
|----------|--------|
| Ctrl + Z | Undo |
| Ctrl + Shift + Z | Redo |
| Ctrl + X | Cut |
| Ctrl + C | Copy |
| Ctrl + V | Paste |

## Search & View

| Shortcut | Action |
|----------|--------|
| Ctrl + F | Search conversations |
| Ctrl + R | Toggle Read Mode / Start Recording |
| Ctrl + , | Open Settings |
| F11 | Toggle Full Screen |

## Messaging

| Shortcut | Action |
|----------|--------|
| Ctrl + N | Compose new message |
| Ctrl + R | Start / Stop recording |
| Ctrl + S | Send message |
| Esc | Clear message / Cancel |

## Accessibility

| Shortcut | Action |
|----------|--------|
| Ctrl + + | Increase text size |
| Ctrl + - | Decrease text size |
| Ctrl + 0 | Reset text size |
| Alt + H | Toggle high contrast mode |

## Alert Management

| Shortcut | Action |
|----------|--------|
| Ctrl + Enter | Confirm active alert |
| Ctrl + E | Trigger emergency SOS |
| Ctrl + L | Open alert log |

## Panel Navigation

| Shortcut | Action |
|----------|--------|
| Ctrl + 1 | Switch to Home panel |
| Ctrl + 2 | Switch to Messages panel |
| Ctrl + 3 | Switch to Log panel |
| Ctrl + 4 | Switch to Settings panel |
